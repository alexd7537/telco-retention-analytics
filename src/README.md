# Código Python

Estos archivos permiten revisar la implementación en GitHub. Para ejecutarlos, descarga y extrae el ZIP completo de la raíz: necesitan los datos, configuración, SQL y otras carpetas incluidas en ese paquete.

- `analyze.py`: limpieza, validaciones, SQLite y consultas SQL.
- `build_notebook.py`: notebook explicativo con resultados.
- `build_report.py`: resumen ejecutivo en PDF.
- `build_powerbi.py`: modelo y páginas de Power BI.
- `design_editorial.py`: diseño editorial del informe.
- `configure_data.py`: configurar la ruta de datos del PBIP sin regenerar visuales.
- `run_project.py`: ejecutar el flujo y sus pruebas.
