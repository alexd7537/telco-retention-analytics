# Consultas SQL

Dialecto SQLite. `00_schema.sql` define el esquema; los archivos `01` a `11` consultan panorama, contratos, antigüedad, factores, segmentos, candidatos y calidad.

La base física `database/telco_retention.sqlite` está dentro del ZIP completo de la raíz. Estos archivos `.sql` son instrucciones, no la base de datos.
